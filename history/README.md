# History

`raid.py` and `raid2.py` are the first version of the raid model. `docs/review.md` cites them by file and line. The review's corrections live in `models/raid_model.py`, which is what the page uses.

File names in the review map to this repo as follows.

| In the review | In this repo |
|---|---|
| raid.py, raid2.py | history/raid.py, history/raid2.py |
| review_check.py | models/raid_model.py |
| lock_sim.py, lock_sim_nf.py | models/leveling_sim.py (the corrected Nightfall version) |
| model.py | models/character.py |
| filler.py, robust.py | analysis/filler_by_level.py, analysis/filler_robustness.py |
| path.py, solo60.py, stack.py | analysis/leveling_paths.py, analysis/solo_builds_60.py, analysis/pact_stacking.py |
